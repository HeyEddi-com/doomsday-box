# Video & motion creative (locked)

**Last updated:** 2026-08-10  
**Status:** Locked for Phase 0 landing; KS bar called out separately  
**Shoot execution:** `product-imagery-brief.md` (sample PCs — shot list + handoff)

## Short answer

**Yes** for the website / pre-launch: motion graphics that explain how it will work **plus** real footage of the box (or chassis) sitting on a table is enough for Phase 0 market intent.

**Not enough alone for Kickstarter submit:** KS hardware rules need a **working prototype** shown honestly for claimed features (or clear disclosure that software/hardware integration is not built yet). CGI must not fake functionality that does not exist.

## Phase 0 — landing / ads (allowed now)

| Shot / piece | Allowed? | Notes |
|--------------|----------|-------|
| Motion graphics: traffic flow, local AI, offline cloud | **Yes** | Label on-screen: **Concept** / **How it will work** |
| Real video: box on desk/table, hands, packaging, ports | **Yes** | Honest “early hardware / prototype chassis” if not final retail unit |
| Voiceover / founder face | **Yes** | Calm, no hype |
| Fake UI screen recordings of features that don’t run yet | **No** | Don’t imply live dashboard if it isn’t bootable |
| Photoreal CGI of a finished product pretending to be real | **No** | Same honesty bar as KS |

### Suggested 45–75s cut

1. Hook (5s) — problem: cloud lock-in / trackers / offline need  
2. Graphics (20–30s) — three pillars: cloud · protection · local AI  
3. Table B-roll (15–20s) — real box, ports, size vs hand/coffee mug  
4. CTA (5–10s) — box.heyeddi.com · $0 list or ≥ $1 intent  

No “Watch the working demo” language until software boots on camera.

## Kickstarter campaign video (later — before submit)

Must include:

- Real prototype in current state  
- Any **promised** hardware/software feature shown working **or** explicitly “not built yet”  
- No CGI/SFx simulating unfinished features  

Table B-roll + concept graphics can **remain** as chapters, but Trust & Safety expects functional proof for gadget claims.

## Landing page placement

- Optional hero/background loop or section **“See the direction”** below fold  
- Not required to collect $0 / ≥ $1 intent  
- Caption: *Concept graphics + early hardware. Working demo comes with the Kickstarter prototype.*
