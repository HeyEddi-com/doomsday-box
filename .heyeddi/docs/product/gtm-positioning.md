## Target audience profiles

1. **Privacy & security hardener** — Dislikes big-tech collection; wants local firewall, ad-tarpitting, and encrypted LAN streaming.  
2. **Local AI enthusiast** — Wants an appliance that runs uncensored, function-calling LLMs (`hermes3:8b`) without API costs.  
3. **Remote worker / digital nomad** — Needs secure **browser-based** access to a home desktop and LAN from locked-down laptops without installing a VPN client.

Maps to existing personas: Morgan ≈ (1), Alex ≈ (2), Casey = backer; remote-worker angle overlaps Alex/Morgan jobs on the appliance.
